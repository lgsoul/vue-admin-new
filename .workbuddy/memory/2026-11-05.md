## 环境坑：Vite 依赖优化 vs WorkBuddy safe-delete

改动 package.json / lockfile 后，Vite 8 启动会重建 `node_modules/.vite/deps`，清理 `deps_temp_*`（>50 文件）时被注入的 `node-safe-delete-shim` 抛 `SAFE_DELETE_BULK_CONFIRM_REQUIRED` 并导致 dev server 崩溃。
处理：把旧缓存目录**重命名保留**（未删除），并用 `NODE_OPTIONS= npm run dev -- --host 127.0.0.1` 启动一次让缓存建全，之后服务稳定。
残留备份：`node_modules/.vite/deps_backup_*`、`node_modules/.vite-temp-backup-*`，可稍后手动清理。
